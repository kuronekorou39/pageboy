# 漫画の置き方

このフォルダに漫画を置くと、起動時に自動で開きます(起動引数や前回開いたフォルダがないとき)。
別の場所(`D:\manga` など)に置いて `O` キーで開いても、同じ規則で動きます。

## 基本の形: 作者フォルダ / 作品フォルダ / 画像

```
library/
  作者A/
    作品1/
      001.png
      002.png
    作品2/
      ...
  作者B/
    [作者B] 作品3 (ジャンル)/     ← 同人系の「[作者] 題名」形式もそのまま使える
      ...
  イラスト集/                      ← 作者で分けないものは直下に置いてよい
    x.png
    y.png
```

ルール:

- **画像が直接入っているフォルダが 1 作品。** 作品の中にサブフォルダは作らない(見るのはライブラリから 3 階層まで)
- **作品フォルダの親が作者。** 親がライブラリ直下なら作者なし
- **フォルダ名が `[作者] 題名` なら角括弧の中を作者にする。** 親フォルダ名より優先。題名は角括弧を除いた残り(`(ジャンル)` などの補足はそのまま表示される)
- **画像の並びはファイル名の自然順。** `1.png, 2.png, 10.png` の順になるので、ゼロ埋めはしなくてよい
- 対応形式: png / jpg / jpeg / webp / avif / gif / bmp。先頭が `.` のファイルとフォルダは無視する
- イラスト詰め合わせなど順番に意味がないフォルダは、アプリ内で `M` を押すとランダム送りになる(作品ごとに記憶される)

## やらなくてよいこと

- タグ付けやメタデータファイルの用意は不要。フォルダ名だけで動く
- 作者とキャラクター・ジャンルの両方で分けたいときは、フォルダは作者で分け、ジャンルは題名の後ろに `(ジャンル)` と書いておく。将来、絞り込み再生を付けるときはこの部分を読む想定

## 注意

- Windows ではフォルダ名に `\ / : * ? " < > |` が使えない。`?` や `:` は全角か別の文字に置き換える
- 作品フォルダを移動・改名すると「最後に読んだページ」と「順番 / ランダム」の記憶は切れる(パスをキーにしているため)
- このフォルダの中身は git に入りません(.gitignore)
